## 実機で電池消費を判定する手順

1. 同一端末・同一サーバー・同じ1秒1行出力で、修正前と修正後を比較する。画面の明るさ、充電状態、開始時の電池残量と温度を揃える。
2. LTE/5GとWi-Fiを分け、前面／背景画面ON／背景画面OFFを各30分測る。適用モードも記録する。接続優先／バランス／省電力優先は別条件として扱う。
3. 測定後は前面で出力が再開し、必要なら再接続できることを必ず確認する。長時間Doze、回線切替、転送中の背景化と転送後のlock解放も別に確認する。
4. 電池残量差だけで断定せず、可能な端末では放電量、CPU時間、WakeLock時間、通信量も採る。同一条件を繰り返し、接続切断・電波変動・他アプリの影響を記録する。
